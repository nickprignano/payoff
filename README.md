# Payoff

A bite-size game theory course for phones: short lessons, instant feedback, a daily streak and
spaced review, with tiny games against bots so the ideas come from playing. For 13 and up.
Plain JavaScript with no build step, for `payoff.prignano.ai`, installable as an app.

Nothing is built yet. The plan is in [docs/SPEC.md](docs/SPEC.md).
